# نظام إدارة وتحليل نتائج الطلاب (Student Results Management and Analysis System)

مشروع تطبيقي باستخدام **JavaScript** لتطبيق مفاهيم **البرمجة كائنية التوجه (OOP)** ودوال المصفوفات (`map`, `filter`, `reduce`).

---

## 📌 الكود المطلوب (`index.js`)

يحتوي الملف على:
1. **كلاس `Student`** بالخصائص (`id`, `name`, `grades`, `attendance`).
2. **الـ Methods**:
   - `getAverage()`: حساب المتوسط باستخدام `reduce`.
   - `getGrade(avg)`: إرجاع التقدير بالحروف (`A, B, C, D, E, F`) باستخدام `if/else`.
   - `getFinalResult()`: إرجاع النتيجة ("ناجح" أو "يحتاج مراجعة") باستخدام `&&`.
3. **المصفوفة `studentsList`**: تضم 4 طلاب مع وجود متعثرين بين 40 و 49.
4. **لجنة الرأفة**:
   - `filter`: استخراج الطلاب بين 40 و 49.
   - `map`: إضافة 5 درجات لمتوسط كل طالب متعثر.
   - `reduce`: جمع المتوسطات الجديدة.
   - حساب متوسط الرأفة العام مع شرط الحماية ضد القسمة على صفر.
5. **المخرجات**: طباعة التقارير والمصفوفات باستخدام `console.log`.

---

## 🚀 طريقة التشغيل

يمكن تشغيل الكود عبر:
1. **Node.js**:
   ```bash
   node index.js
   ```
2. **المتصفح**: نسخ الكود ولصقه مباشرة في شاشة الـ Console (`F12`).
